## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>Does this Facebook modification require Root or Magisk/KernelSU?</b></summary>
<br/>
No. MetaKiller is packaged as a standalone Android application. You do not need root access, custom recoveries, or Xposed frameworks. Simply install the APK directly.
</details>

<details>
<summary><b>Is this unofficial Facebook client safe to use?</b></summary>
<br/>
Yes. MetaKiller operates strictly on the local device layer. It does not automate interactions, use third-party tracking libraries, or intercept account credentials. All media downloads connect directly to official Facebook CDN servers.
</details>

<details>
<summary><b>Why are all features disabled after installation?</b></summary>
<br/>
MetaKiller adheres to a privacy-first, user-choice principle. Instead of forcing modifications automatically, you retain complete authority over which features to activate.
</details>

<details>
<summary><b>How do updates work for MetaKiller?</b></summary>
<br/>
MetaKiller features a built-in OTA update checker linked directly to this repository's <code>update_config.json</code>. Whenever a new version is released on GitHub, you will receive an in-app prompt containing the changelog and a direct download button.
</details>
